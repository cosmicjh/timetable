| Worker | school-timetable |
| 제공 방식 | Workers Static Assets + 같은 Worker의 /api/* |
| 정적 출력 / 바인딩 | dist/ / ASSETS |
| Cloudflare 계정 ID | 965071bae1ca798003675034b0ce7ce5 |
| D1 | school-timetable-db, APAC |
| D1 ID / 바인딩 | c4c3186c-bcfa-4bb9-959f-5086151abce8 / DB |
| 스키마 | 0001_timetable.sql 원격 적용 완료 |
| Secret | PASSWORD_PEPPER, BOOTSTRAP_TEACHER_HASH, BOOTSTRAP_ADMIN_HASH 등록 완료 |
| 배포 도구 | Wrangler 4.156.0, 잠금 파일과 package.json에 고정 |
| 배포 명령 | pnpm run deploy |
| workers.dev / 미리보기 URL | 켜짐 / 꺼짐 |

Secret 실제 값은 Git·공개 자산·보고서에 넣지 않았습니다. 복구용 초기 인증값은 Git 제외 `private/bootstrap.local.json`에 있습니다. 해당 파일과 PASSWORD_PEPPER를 안전하게 보관합니다. 배포용 토큰을 대화에 붙여 넣을 필요는 없습니다.

Wrangler 4.154.0의 첫 시도는 정적 자산 업로드에서 401을 반환했습니다. 4.156.0으로 재시도하여 16개 정적 파일과 Worker를 정상 업로드했습니다. 이후 재배포도 같은 버전으로 재현하도록 의존성을 고정했습니다.

## 실제 서비스 검증

HTTPS에서 네 화면·정적 JS와 D1 health 응답을 확인했습니다. 없는 /api 경로는 HTML 대신 404 JSON을 반환합니다. src·tests·private·.dev.vars는 공개되지 않습니다. 교사·관리자 로그인, 서버 권한, HttpOnly/Secure/SameSite 쿠키, 로그아웃 후 기존 세션 차단, 변경 요청 출처 검증, no-store를 실제 서비스에서 검증했습니다.

재현 가능한 원격 검증은 `node scripts/verify-remote.mjs https://school-timetable.cosmicjh.workers.dev`입니다. 기본 초기 비밀번호를 변경한 뒤에는 검증 전용 환경변수 TIMETABLE_TEST_PASSWORD를 안전하게 설정해야 합니다. 이 검증은 로그인/로그아웃만 수행하고 학생 자료를 등록하거나 수정하지 않습니다. 실제 브라우저에서도 관리자 로그인·빈 학생 목록·로그아웃·모바일 화면과 동일 출처 요청을 확인했습니다.

운영 DB에는 가상 학생을 넣지 않았습니다. 학생·분반·배정·교사·백업은 모두 0건, 최초 역할 계정만 2건입니다. 실제 운영 자료를 이관했다고 보고하지 않습니다.

## 사용자가 진행할 작업

1. 관리자에 `1234`로 로그인하고 설정에서 교사·관리자 비밀번호를 각각 변경합니다. 초기 계정 생성과 Cloudflare 배포를 위한 추가 로그인은 필요하지 않습니다.
2. 기존 JSON 백업 또는 엑셀 5개를 등록합니다. 이관 후 새 백업을 내려받아 [이관 대조 절차](MIGRATION.md)를 실행합니다.
3. GitHub push 시 자동 배포도 원하면 아래 연결을 한 번 설정합니다. 현재는 Wrangler로 배포 완료된 상태이며 GitHub와 Cloudflare의 자동 배포 연결은 아직 없습니다.

## GitHub 자동 배포 연결

현재 Wrangler OAuth로 Worker와 D1 배포는 가능하지만 Workers Builds API는 403을 반환했습니다. 이 API는 별도의 Workers Builds Configuration 권한을 요구하므로 기존 인증으로 GitHub 연결을 만들지 않았습니다. [공식 권한 안내](https://developers.cloudflare.com/workers/ci-cd/builds/api-reference/)

[Cloudflare의 school-timetable 설정](https://dash.cloudflare.com/965071bae1ca798003675034b0ce7ce5/workers/services/view/school-timetable/production/settings)에서 **Builds → Connect**를 선택합니다. GitHub 승인이 표시되면 `cosmicjh/timetable` 저장소 접근을 허용하고 아래 값을 사용합니다. [공식 기존 Worker 연결 절차](https://developers.cloudflare.com/workers/ci-cd/builds/)

| 설정 | 값 |
| --- | --- |
| 저장소 | cosmicjh/timetable |
| 운영 브랜치 | codex/workers-d1 |
| 루트 | / |
| Build command | pnpm build |
| Deploy command | pnpm run deploy |
| Worker 이름 | school-timetable |

이미 등록한 D1 바인딩과 세 개 Secret을 그대로 사용합니다. 새 D1이나 새 Worker를 만들지 않습니다. main으로 연결하면 아직 이전 Apps Script 화면이므로 현재는 위 브랜치를 선택해야 합니다. main 전환은 기존 GitHub Pages 게시 원본 보존 후 별도로 진행할 수 있습니다.
